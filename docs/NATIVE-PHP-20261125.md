# مهاجرت کامل سیزده به PHP — ۲۵ نوامبر ۲۰۲۶

تمام صفحات عمومی شامل خانه، درباره، فهرست و جزئیات خدمات، فهرست و جزئیات پروژه،
فهرست و جزئیات مقاله، دسته‌بندی‌ها و برچسب‌ها، تماس، قوانین، حریم خصوصی و خطاها
با `App\View\PublicPage` و قالب‌های `resources/views/site` رندر می‌شوند. کنترلرها
همچنان همان داده‌های مدیریت‌شده در پنل را می‌خوانند؛ دیتابیس بازسازی یا منتقل نشده است.

قالب‌ها از ساختار و کلاس‌ها و CSS نسخهٔ قبلی منتقل شده‌اند. آرشیو مرجع Vue در
`dist/cpanel/sizdah-vue-reference-20261125.zip` نگهداری شده و بخشی از نصب هاست نیست.
رندر قالب به Node، Vue، Inertia یا پروسهٔ SSR وابسته نیست. نسخهٔ قبلی مرورگر که
هنوز باز باشد، با پاسخ `409 / X-Inertia-Location` به بازدید کامل ارتقا پیدا می‌کند.

## رفتار و ظاهر

منو و زیرمنو، مودال دانلود، انتخاب خدمات و کشور، اعتبارسنجی فرم‌ها، امتیازدهی،
فیلتر گالری، اشتراک‌گذاری، اسلایدر پروژه، نظرات و نوار مشتریان/تیم حفظ شده‌اند.
تعامل‌ها در `resources/js/site.ts` پیاده شده‌اند؛ فرم تماس و دانلود علاوه بر POST
معمولی پاسخ JSON برای نمایش وضعیت در همان صفحه دارند. آزمون مرورگر درخواست‌های
ارسال فرم را شبیه‌سازی می‌کند و پیام واقعی نمی‌فرستد.

متن و تصاویر از پاسخ PHP نمایش داده می‌شوند؛ هیچ `data-page` یا دیکشنری ترجمه یا
جدول مسیرهای JavaScript به مرورگر فرستاده نمی‌شود. CSS و فونت‌ها و رسانه‌های برند
حفظ شده‌اند. GSAP فقط روی دستگاه با اشاره‌گر دقیق، بعد از load و فرصت idle بارگیری
می‌شود؛ موبایل لمسی آن را دریافت نمی‌کند. انیمیشن‌های پیوسته خارج از دید یا در تب
مخفی متوقف می‌شوند و تنظیم کاهش حرکت سیستم رعایت می‌شود.

سایت و پنل فقط فارسی و RTL هستند. تنظیم زبان انگلیسی پنل، تنظیمات زبان‌های غیرفعال،
انتخاب زبان و کشف alternateهای صفحات حذف شده‌اند. آدرس‌های `/fa` و جداول محتوای
موجود حفظ شده‌اند تا لینک‌ها و داده‌های پنل از بین نروند. پیش‌شمارهٔ کشورها در فرم
تماس یک قابلیت ورودی تلفن است و ارتباطی با چندزبانه‌بودن سایت ندارد.

## نصب

بستهٔ کامل `dist/cpanel/sizdah-native-php-20261125.zip` خروجی آمادهٔ هاست است.
روی سیستم توسعه ساخته می‌شود؛ روی هاست به npm، Composer یا Node نیاز نیست.
فایل‌های `app`، `bootstrap`، `config`، `resources`، `routes`، `vendor` و سایر فایل‌های
برنامه را در محل برنامه ادغام کنید. در نصب جداگانهٔ cPanel، محتوای `public` در
`public_html` قرار می‌گیرد، به‌خصوص `build` و `site`. فایل‌های `.env`، دیتابیس و
`storage` هاست حفظ شوند. migration جدید لازم نیست. پیش از جایگزینی بکاپ تهیه کنید.

کش قالب‌ها، تنظیمات و صفحات را پس از نصب پاک کنید:

```bash
php artisan view:clear
php artisan config:clear
php artisan tinker --execute='\App\Services\Performance\PageCache::flush();'
```

بدون ترمینال، فایل تولیدشدهٔ `bootstrap/cache/config.php` و فایل‌های PHP تولیدشده
در `storage/framework/views` پاک و کش صفحات از بخش «عملکرد» پنل purge شود.
دارایی‌های جدید را پیش از manifest جدید آپلود کنید. نصب این بسته روی هاست در این
جلسه انجام نشده است؛ اعداد Lighthouse باید بعد از نصب روی همان هاست اندازه‌گیری شوند.

## بررسی

`npm run build` و `npm run lint`، تست‌های PHP و اسکریپت
`node scripts/verify-native-site.mjs` برای بررسی استفاده می‌شوند. اسکریپت مرورگر
PHP محلی راه‌اندازی می‌کند و منو، مودال، فرم، انتخاب کشور، پاسخ خطا و نمایش بدون
JavaScript را بررسی می‌کند. تصاویر موبایل و دسکتاپ در `test-results/blade-verified`
ذخیره می‌شوند. مسیر Chromium با `CHROMIUM_PATH` قابل تنظیم است.

این مهاجرت به‌تنهایی تضمین‌کنندهٔ عدد مشخص LCP/TBT یا رتبهٔ سئو نیست؛ زمان پاسخ
هاست، تصاویر آپلودی، فونت‌ها و تنظیمات GTM همچنان در نتیجه اثر دارند.

### نتیجهٔ بررسی نهایی

تمام ۲۹۵ تست PHP پاس شدند. بیلد TypeScript/Vite و lint موفق بودند. بررسی مرورگری
۱۱ مسیر در دو عرض ۴۰۲ و ۱۴۴۰ انجام شد؛ منو، مودال و پاسخ موفق فرم، انتخاب خدمات،
جستجوی کشور و پیام اعتبارسنجی نیز پاس شدند. نمایش هیرو با JavaScript خاموش تأیید شد.
فایل اصلی JavaScript عمومی ۱۶٬۳۵۵ بایت (حدود ۶ کیلوبایت gzip) است؛ هیچ فایل Vue
یا entry قبلی app.ts در manifest خروجی وجود ندارد. بررسی بسته، نبود `.env`،
دیتابیس، storage و فایل‌های Vue را تأیید کرد.
